# ragops-lab

Evaluation-first RAG and LLMOps platform for production-grade document question answering.

This repository is designed for AI engineer, LLM engineer, applied AI, and MLOps roles. The emphasis is not merely retrieval augmented generation, but evaluation, traceability, regression testing, cost control, and deployment.

## Goal

Build a local-first RAG platform that ingests documents, retrieves evidence, generates grounded answers, evaluates the result, and stores traces for analysis.

## Core capabilities

- Document ingestion pipeline.
- Hybrid retrieval with lexical and vector search.
- Answer generation with provider-agnostic LLM client.
- Evaluation of faithfulness, relevance, context precision, citation support, and refusal quality.
- Prompt regression tests.
- API service for ingestion, search, question answering, and evaluation.
- Trace storage, cost tracking, and latency tracking.
- Docker Compose for local deployment.
